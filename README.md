# VCTM Sessional ERP - Frontend Portal

Autonomous Sessional Assessment & Learner Classification Portal for Vivekananda College of Technology and Management, Aligarh.

## Highlights
- **Collegiate Branding**: Official VCTM crest, responsive layout, and institution color palette (`#1B2A4A`, gold/amber accents).
- **Authentication**: Secured via Supabase Authenticator (credentials provisioned by system administrator).
- **Evaluation Management**: Continuous assessment for T1, T2, Quiz, TA, and IE scores.
- **Learner Classification**: Automated Fast/Average/Slow classification with official letter drafts and Excel report exports.

## Vercel Deployment
1. Connect this repository to your [Vercel](https://vercel.com) account.
2. Select **Other** as the Framework Preset.
3. Keep the root directory as `./`.
4. Deploy!
